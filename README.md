# 小屋里的他 · Pixel Autonomous Life

一个只能观察、不能控制的 2D 像素生活模拟器。

## 项目概念

林默住在一间带院子的小屋里。他有自己的认知、兴趣、记忆和判断，不会等待玩家指令，页面上也没有任何操作按钮。

你可以看到他：

- 按自己的状态起床、做饭、吃饭、休息和睡觉
- 在卧室、厨房、书房、起居室和院子之间走动，绕开墙和家具
- 研究加密货币和美股，并在研究够了之后做很小的虚拟仓位
- 进行力量训练，或因为没练而在第二天更想练
- 找工作；录用是概率事件，不是第几次就一定成功
- 工作后获得收入，吃饭会花钱
- 随精力、饥饿、心情、存款，以及当下的情绪改变下一步
- 自己挑一门手艺练（做饭、吉他、画画、交易纪律），会卡住，也会忽然练顺
- 做错事之后后悔，把教训留下来，并在之后的选择里照做或渐渐淡掉
- 每天夜里写一则日记，偶尔对生活有一次醒悟
- 存款紧时焦虑，从院子的门出去打散工，回来又累又有一点现金
- 有余钱时买手机、电脑、沙发、器械或吉他，东西会留在屋子里
- 日子会往上走，也会往下散；轨迹画在小屋下方的折线上

## 人格设定

- 认知水平：92 / 100
- 长期兴趣：加密货币、美股、健身
- 风险偏好：先研究，再行动
- 生活模式：自主决策，不接受玩家控制

认知会体现在行为上：求职写得更清楚、亏损时不急着砍仓、虚拟仓位很小，而且至少认真看过两次行情才允许买入。

## 他如何做决定

没有固定时刻表。每次做完一件事，他会给下一步打分，再用带温度的随机抽取，所以同样的早晨可能去锻炼，也可能先看盘。

分数来自：

- 当前精力、饥饿、心情、存款
- 昼夜节律：夜里更容易困，白天只是软偏好（午饭时间更想吃饭，但肚子不饿就可以不做）
- 人格：研究欲、健身兴趣、先研究再下手
- 记忆：昨天没吃好、没练、被拒、亏钱，会轻轻推着今天的选择
- 一点当天的念头和噪声，让日子彼此不一样

## 需求与后果

- 饥饿高会推着他去吃饭；吃下去饥饿下降、心情回升，并且扣除食材或外卖的钱
- 精力低会推着他休息或睡觉；训练和工作会额外消耗精力
- 没工作时会看招聘。每一封都有成功率，状态差或一天投太多，成功率会下降
- 录用后从第二天开始远程工作，按时长拿收入
- 市场是完全虚拟的，不连接真实账户。价格会波动，研究不够、刚亏过、或现金要留作生活费时，他选择观望
- 买入后可能赚也可能亏，心情会跟着动，但不会被短期波动完全带着走

## 记忆

他记得最近的事件，也记得昨天的一句总结（吃了几顿、练没练、投了几份简历或上了多久班、市场盈亏、存款）。这些会进入下一天的选择，也会变成当下的念头。念头是按情境拼出来的，不是写死的几句台词。后悔、教训和醒悟也会写进念头里，引用的是他自己经历过的事。

## 情绪、手艺和领悟

情绪有喜悦、焦虑、孤独、自豪、后悔、希望和怀念。它们有自己的原因：下雨会让他怀念，录用会抬起希望，手痒亏损会堆起后悔和焦虑。情绪会随时间回到各自的日常水位，同时轻轻推动下一步（很饿、很困、没钱时，身体和存款仍然比情绪更响）。

他会自己选一门当天想练的手艺。经验涨得慢，等级越高涨得越少；练到平台期会卡住，偶尔突破。做饭等级会让一餐更便宜、心情更好；交易纪律和「先复盘再动手」的教训会降低冲动下单的可能。冲动买入会立刻吃到一笔浮亏。

失误包括手痒交易、熬夜、睡过头、跳过训练、心情不好时晚饭多花钱。同一天同一类只记一次。事后后悔，并留下一条教训。教训有强度：照着做会加深，几天不碰会变淡，淡到一定程度就忘。强度够了，可能变成一次醒悟，改写他对健康、手艺、平静和钱的看重，从而改变以后的优先级。

每天睡觉前和午夜，他会按当天的天气、饮食、训练、工作或求职、盈亏、存款、练习和失误写一则日记。同一天只保留最新的一则。小屋下方能看到此刻的情绪、手艺进度、日记，以及教训和醒悟。这些和存款、记忆一起存在 `localStorage` 里，旧存档缺了这些字段时会用默认值补上。

## 钱、散工和生活轨迹

存款紧的时候，焦虑会抬起来，觉睡得浅，心情也差一点，念头里会提到钱。他会从院子南边的门走出去打散工：送外卖、搬箱子或发传单。人离开画面，回来时精力下降，这一趟的现金进账。每天有房租；手机、电脑、器械还有订阅。付不起时，差额记成欠款，房租拖着，夜里更不安。

余钱够了，他会买新手机、新电脑、更软的沙发、更好的器械或一把新吉他。一时看上的小东西可能事后后悔。买下的东西画在对应的位置：电脑和手机在书桌上，吉他在起居室，器械在哑铃旁边，沙发靠墙。新电脑会抬高时薪，也让画画和交易练得稍快；吉他让练琴更快；器械让训练少耗一点精力；沙发让休息更舒服。

生活轨迹按习惯加减：训练、正经吃饭、上班、散工、练手艺、存款和照做的教训往上；垃圾餐、旷工、欠款、手痒交易、冲动消费、熬夜和赖在床上往下。分数有阶段：从容、上坡、稳住、摇摆、下滑、下沉、谷底。掉到谷底可能出现一次醒悟，想把日子拉回来；顺得很久、钱也够，可能松手。小屋下方有一条按天画的折线，旁边标着当前阶段。

收入面板写着职位、时薪或「还没有」、今日散工、本月收入和支出、净资产、欠款，以及屋子里的新东西。最近进出账列出工资、散工、房租、订阅和购物。职业从初级远程设计师往上：干得稳可能涨时薪或升到资深、主管；连续旷工、表现差可能被辞；已经在职时，表现够了也可能跳去更好的位置。

## 存档

状态写在浏览器的 `localStorage`（键名 `linmo-pixel-life-v1`）。

关掉页面再打开，他会从上次的时间、位置、存款和记忆继续。若中间过了一段现实时间，会按大约「现实 1 秒 = 模拟 5 分钟」补上，最多补 36 小时，避免一次补太久把页面卡住。

## 运行方式

最简单的方式是直接用浏览器打开 `index.html`。

也可以在项目目录启动本地静态服务器：

```powershell
python -m http.server 8000
```

然后访问：

```text
http://127.0.0.1:8000/index.html
```

## 画面

屋子是俯视的 16×16 地砖，画在画布上再按整数放大，边缘保持清晰。没有外部贴图。

- 卧室、厨房、书房、起居兼健身的区域，都有各自的地板和家具
- 院子有草地、花、石径、栅栏和树，南边留着一扇可以走出去的门
- 买下的电脑、手机、吉他、器械和沙发会留在对应的房间里
- 林默有朝上、下、左、右四个方向的多帧走路，停下后会坐着、做饭、吃饭、打字、举铁或躺下睡觉。打散工时他会走到门口，然后离开画面
- 他只走能落脚的格子，用正交寻路绕开墙和家具
- 夜里房间会暗下来，床头、厨房、客厅、书桌和门口的灯留下暖色光晕

旧存档如果还是上一版的等距坐标，会把他放到当前这件事该站的格子上。存款、天数和记忆照旧延续，键名仍是 `linmo-pixel-life-v1`。

## 技术说明

- 单文件 HTML
- Canvas 像素画面，16×16 地砖，画面坐标是世界坐标的 2 倍
- 自动昼夜循环（灯光跟着钟点走，他的行动不跟着时刻表走）
- `window.render_game_to_text()`：观察用快照，包含所在格子、朝向、姿势、决策理由、分数、记忆、清醒时间、虚拟持仓，以及情绪、手艺、教训、醒悟和最近的日记。另外带上 `finances`（现金、欠款、净资产、职位、时薪、本月收支、今日散工、拖欠房租、已购物品、最近账目）和 `trajectory`（分数、阶段、转折、最近几天的历史）
- `window.advanceTime(ms)`：按模拟步长推进时间

存款条以 ¥4000 为满格，旁边的数字是真实存款。连续清醒时间从他起床开始计，睡觉时显示「睡眠中」。

## 当前限制

这是一个轻量原型。市场研究只在模拟里买卖虚拟标的，不连接真实交易账户，也不会执行真实买卖。决策是效用打分、记忆、情绪和教训，不是完整的认知架构。日记和念头用当天的真实状态拼出来，不调用外部接口。
