# 小屋里的他 · Pixel Autonomous Life

一个只能观察、不能控制的 2D 像素生活模拟器。

## 项目概念

林默住在一间带院子的小屋里。他拥有自己的认知、兴趣、生活节奏和判断，不会等待玩家指令。

你可以看到他：

- 起床、做饭、吃饭、休息和睡觉
- 在屋内不同房间之间移动
- 研究加密货币和美股
- 进行力量训练和健身
- 找工作、获得远程工作机会
- 随精力、饥饿、心情和存款变化调整生活

## 人格设定

- 认知水平：92 / 100
- 长期兴趣：加密货币、美股、健身
- 风险偏好：先研究，再行动
- 生活模式：自主决策，不接受玩家控制

## 运行方式

最简单的方式是直接用浏览器打开：

```text
D:\home\index.html
```

也可以在 `D:\home` 中启动本地静态服务器：

```powershell
python -m http.server 8000
```

然后访问：

```text
http://127.0.0.1:8000/index.html
```

## 技术说明

- 单文件 HTML
- Canvas 像素画面
- 等距/剖面式立体房屋
- 自动昼夜循环
- 暴露 `window.render_game_to_text()` 供观察和测试
- 暴露 `window.advanceTime(ms)` 供确定性时间推进

## 当前限制

这是一个轻量原型。市场研究目前表现为生活行为和思考内容，不连接真实交易账户，也不会执行真实买卖。

## 后续方向

- 更细致的认知、记忆和决策系统
- 多个居民与关系网络
- 更复杂的工作、收入和失业经历
- 投资组合的虚拟演化
- 健身计划、身体状态和长期习惯
- 存档与跨天持续生活
